01 · ProductWaste & circularity tech

Kolekt

A waste marketplace platform where people buy and sell recyclables (plastic, clothes, mixed waste, beverage cartons and metals) for money, and earn reward points on every transaction that can later be converted into money.

RoleSole full-stack developer, also the client's business analyst
Duration2+ years
Users1,000+ on a live legacy platform
StackLumen · Vue · Nuxt · MySQL · AWS

The challenge

I joined as the only full-stack developer on a legacy application already serving 1,000+ users. I had about a month of handover, and no prior background in API development, Lumen or Vue.js. From day one I had to learn the codebase and the stack while building new APIs for the project, without affecting existing users.

★ What I'm proudest of: the transaction & points revamp

  • Redesigned the entire transaction flow for buying and selling waste, where money changes hands, across both backend and frontend.
  • Rebuilt the points system: the reward points users earn on each transaction and their conversion into money.
  • Made the changes on a live platform while keeping existing users and data working.

APIs for mobile apps & admin

  • Built and maintained the REST APIs in Laravel Lumen behind the mobile apps and admin dashboard.
  • Introduced API versioning so new features shipped without breaking apps already in users' hands.
  • Implemented authentication and authorization and documented endpoints with Swagger and Postman.

Selling methods & integrations

  • Face recognition-based selling, so users can be identified at the point of sale.
  • SMS and push notification-based selling flows and user notifications (Twilio).
  • Payment gateways for payment processing and AWS S3 for file and media storage.

Admin dashboard (Nuxt.js)

  • Managed, maintained and updated the Nuxt.js / Vue.js admin dashboard.
  • Added new features for the operations team as the business grew.

Production & data

  • Owned production deployments and critical hotfixes.
  • Investigated issues with AWS CloudWatch Logs, and optimized MySQL schemas and queries.

Business analysis

  • Acted as the founder's business analyst alongside development: ran requirements conversations and translated business ideas into user stories and technical tasks.
  • Analysed how changes, such as the transaction and points revamp, would affect existing users and data before building them.
  • Provided estimates, planned releases and kept consistent communication and follow-up, which the founder highlighted in his recommendation.
The takeaway: I went from no API experience to owning the backend, the admin dashboard and the most critical business flow of a live product. It's how I learn best: on real systems, with real users depending on them.
